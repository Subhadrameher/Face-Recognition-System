How it works

1. OpenCV detects each face. 2. A pretrained {{ model }} network (via DeepFace) turns the face into a 512-number embedding. 3. The embedding is compared with stored embeddings using cosine similarity. 4. If the best score is at least {{ threshold }}, the person is named; otherwise the result is Unknown.

Stack: Python, Flask, OpenCV, DeepFace, NumPy, scikit-learn, SQLite, Bootstrap 5, Chart.js.

Privacy notice
  • Faces are registered only with the person's consent.
  • Photos are not saved; only embeddings are stored locally in SQLite.
  • Embeddings are never returned by any API.
  • Deleting a person permanently removes their data.
  • Not for covert identification or surveillance.
